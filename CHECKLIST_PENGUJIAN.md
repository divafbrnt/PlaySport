# Checklist Demo PlaySport / Poin a-g

- [ ] Open project, Gradle Sync berhasil.
- [ ] Run di emulator / HP, beranda memuat enam lapangan dan gambar.
- [ ] Filter olahraga berfungsi.
- [ ] Tombol Booking membuka form dan ID lapangan yang benar.
- [ ] Form kosong menampilkan error validasi, aplikasi tidak crash.
- [ ] Nomor HP tidak valid ditolak.
- [ ] Tanggal kemarin ditolak.
- [ ] Durasi dan jam yang melewati 22:00 ditolak.
- [ ] Total harga langsung berubah saat input durasi diubah.
- [ ] Simpan booking berhasil dan tampil di Booking Saya (CREATE + READ).
- [ ] Edit booking lalu simpan berhasil (UPDATE).
- [ ] Batalkan booking melalui dialog konfirmasi (DELETE).
- [ ] Pesan slot bentrok muncul jika lapangan/tanggal/jam sama.
- [ ] Isi form masih terjaga saat perangkat dirotasi (rememberSaveable).
- [ ] Data booking tetap ada setelah aplikasi ditutup dan dibuka ulang (Room lokal).
